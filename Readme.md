# CareerLaunch AI

CareerLaunch AI is a modern career management platform designed to help students organize, track, and accelerate their professional growth. The platform provides dedicated tools for skill tracking, project management, internship application tracking, analytics, and profile management in a single dashboard.

## Project Overview

Students often struggle to keep track of their technical skills, personal projects, internship applications, and overall career progress. CareerLaunch AI solves this problem by providing a centralized platform where users can:

* Track learning progress and technical skills
* Manage personal and academic projects
* Monitor internship applications and hiring pipelines
* Analyze career growth through visual dashboards
* Maintain a professional profile
* Export career information for future opportunities

## Local Storage Keys

The application stores user data locally using browser LocalStorage.

| Key                      | Purpose                        |
| ------------------------ | ------------------------------ |
| careerlaunch_profile     | User profile information       |
| careerlaunch_skills      | Skills and progress data       |
| careerlaunch_projects    | Project records                |
| careerlaunch_internships | Internship application records |

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using CareerLaunch AI.

No backend setup or installation is required.
